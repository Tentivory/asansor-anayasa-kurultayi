# Asansör Anayasa Kurultayı

> **Resmî duyuru:** Bu depo, dünya tarihinde ilk kez *asansör arızası* ile *anayasa yazımını* birleştiren uluslararası ölçekte bir girişimdir. Birleşmiş Milletler henüz bizi aramadı; sabırsızlıkla bekliyoruz.

## Bu proje ne yapar?

Python çalıştığında hayali bir asansör durur. İçindeki üç kişi (bir mühendis, bir şair, bir kedi bakıcısı) kendilerini *geçici kurucu meclis* ilan eder. 12. kat ile zemin arasında evrensel maddeler kabul edilir. Hiçbir madde patates içermez. Bu bir ilkedir.

## Kurulum

```bash
python3 kurultay.py
```

Bağımlılık yoktur. Asansör de yoktur. Hayal gücü zorunludur.

## Kabul edilen temel maddeler (simülasyon çıktısı)

1. Asansör kapısı açılmadan karar alınamaz.
2. Çay ikramı anayasal bir haktır.
3. Kedi bakıcısının vetosu vardır; gerekçe göstermek zorunda değildir.
4. 13. kat yoktur. Tartışma kapalıdır.
